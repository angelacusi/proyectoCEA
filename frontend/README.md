# Proyecto CEA - Frontend

## Requisitos previos

- Node.js 20.19 o posterior (o 22.12 o posterior), que incluye npm.

## Instalación de Node.js

Descarga la versión LTS desde [nodejs.org](https://nodejs.org/) e instálala.

Verifica la instalación en CMD o PowerShell:

```bash
node -v
npm -v
```

## Instalar y ejecutar

Desde la carpeta `frontend`:

```bash
npm install
npm run dev
```

El backend debe estar activo en `http://localhost:8000`. Abre el frontend en
`http://localhost:5173`.
